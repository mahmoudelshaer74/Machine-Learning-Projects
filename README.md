## 🛠️ Advanced Engineering Core Competencies

Through these implementations, I have engineered and applied the following professional practices:

* **Production-Oriented ML Pipelines:** Designing modular preprocessing and training workflows with reusable Python functions, serialized model artifacts, and structured project architecture.

* **Production Deployment:** Wrapping serialized machine learning pipelines (`.pkl` and `.sav` files) into interactive web applications and dashboards using **Streamlit**.

* **Advanced ETL Pipelines:** Building flexible Python workflows capable of processing CSV, JSON, XLSX, TXT, and **SQLite3 relational databases**.

* **Feature Engineering & Data Preprocessing:** Applying transformations such as `StandardScaler`, `RobustScaler`, logarithmic transformations, categorical encoding, and domain-specific feature extraction.

* **Imbalanced Classification:** Handling highly imbalanced datasets using **SMOTE, Random Over-Sampling, Random Under-Sampling, and Class Weighting**.

* **Ensemble Learning:** Combining multiple machine learning models using **Soft Voting** to improve predictive performance and robustness.

* **Hyperparameter Tuning:** Fine-tuning machine learning estimators using **GridSearchCV** and cross-validation techniques.

* **Threshold Optimization:** Moving beyond the default `0.5` classification threshold by optimizing the decision threshold according to **F1-Score** and the Precision-Recall trade-off.

* **Model Evaluation:** Evaluating classification and regression models using task-specific metrics including **F1-Score, Precision, Recall, PR-AUC, ROC-AUC**, and other performance measures.

* **Model Explainability & Error Analysis:** Analyzing feature importance, confusion matrices, false positives, and false negatives to better understand model behavior.
