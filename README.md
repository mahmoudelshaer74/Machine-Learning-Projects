## 🛠️ Advanced Engineering Core Competencies
Through these implementations, I have engineered and applied the following professional practices:
* **Production Deployment:** Wrapping serialized machine learning pipelines (`.pkl` and `.sav` files) into interactive web UI dashboards using **Streamlit**.

* **Mathematical Optimization:** Feature engineering utilizing statistical scaling (`StandardScaler`, `LabelEncoder`) and determining cluster centroids via the mathematical **Elbow Method (WCSS)**.
